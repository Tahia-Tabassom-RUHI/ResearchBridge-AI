# Shiney's discovery demo

The promise: “You don't need research vocabulary to start. Tell us what you are
curious about, correct our interpretation, and choose a real paper.”

Use the memory example first; it is easy to relate to as a student. Keep the
walkthrough short: question → notice bubble sizes/colors → move two circles →
find results → choose Authors → tap a bubble → preview and add an item → reading
mode. Tap the Vault icon to open another study set.
Try the white/teal theme button on the slim icon strip.
For a question outside the built-in examples, the extra topic bubbles come from
retrieved source terms without an AI key. Bookmark the vault URL to reopen a
saved study set after refreshing the app.

Live AI needs a Hugging Face token or Gemini key in Optional live AI, plus the live AI checkbox.
Without it, say “guided search” rather than claiming a model is running. Live
paper retrieval requires no project account. Do not claim best in the world,
scientific consensus, full-text analysis, or verified peer review from metadata.

From a paper with an abstract, choose “Learn this paper” to open Tahia's guided
reading prompts. Save one reflection and return to the paper. The Worker in the
repository is a local mock; do not describe it as live AI. Tahia's optional
evidence-checked explanation pack requires separately configured free provider
credentials. Without those, guided reading still works.

If services are down: load a saved real search in Rehearsal & example tools and
say that it is a saved retrieval. Original source links and timestamps remain.
In the workspace, folders, notes, links and drawings stay in this browser. Paper
previews contain retrieved abstracts, not complete PDF files. Background article
text comes from Wikipedia with attribution. Bubbles count only the retrieved
sample; they do not rate trust.
Use Export in the note board to download Markdown notes. The Original page tab
can display a source inside the app when its publisher allows embedding.

One-time free AI setup: get a Hugging Face token with Inference Providers permission
at https://huggingface.co/settings/tokens. Use a free account without purchased
credits or billing, paste the token into the app's password field, enable live AI,
and resubmit the question. The app allows two Hugging Face calls per session.
Never paste the token into chat or Git. Without one, demonstrate the no-key path.
