# Shiney's discovery demo

The promise: “You don't need research vocabulary to start. Tell us what you are
curious about, correct our interpretation, and choose a real paper.”

Use the memory example first; it is easy to relate to as a student. Keep the
walkthrough short: question → direction → three results → abstract → source link.
The bubbles are optional refinement, not the opening screen.

Live AI needs one Gemini key in Demo setup and the live AI checkbox enabled.
Without it, say “guided search” rather than claiming a model is running. Live
paper retrieval requires no project account. Do not claim best in the world,
scientific consensus, full-text analysis, or verified peer review from metadata.

The learning coach button is a selected-paper handoff placeholder pending joint
integration with Ru. Demonstrate working discovery rather than implying the
classroom is complete.

If services are down: load a saved real search in Rehearsal & example tools and
say that it is a saved retrieval. Original source links and timestamps remain.

One-time AI setup: visit https://aistudio.google.com/api-keys, obtain a key for an
eligible free-tier project, paste it into the app's password field, enable live AI,
and resubmit the question. Check quota there. Never paste the key into chat or Git.
Free-tier prompts may be used to improve Google's products; use public study topics.
